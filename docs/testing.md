# Testing checklist

- [ ] Android Gradle sync succeeds.
- [ ] Debug APK builds successfully.
- [ ] Application launches on the intended Fire OS target.
- [ ] D-pad, Select and Back navigation work without a mouse.
- [ ] Search, genre filters and favorites work.
- [ ] Video starts, pauses, seeks and exits cleanly.
- [ ] Broken/offline video shows a useful failure state.
- [ ] Backend `/health`, `/api/titles`, and `/api/recommendations` endpoints work.
- [ ] TV connects to the configured backend URL.
- [ ] AI provider configuration and local fallback tested.
- [ ] Demo video under three minutes shows the app running on the intended target.
- [ ] README, license, product feedback and submission fields are complete.

Standard Android emulator testing alone is not evidence of Fire TV track compliance.
